## Scope

This evidence records the repository and operational policy that keeps private
Student import data outside Git and CI. It also records the reusable guard that
P1-06 must run in CI. P0-04 does not create a GitHub Actions workflow or the
P2-07 Laravel import command.

## Private source relocation

The single local private source was moved from the repository root to an
access-controlled private directory outside the repository on the same local
drive. Its content was not read or printed.

The move verification reported:

- exactly one known repository source before the move;
- no pre-existing destination copy;
- matching source/destination SHA-256 values;
- zero remaining copies in the repository;
- no Git-tracked private source.

The real destination path is intentionally omitted. The runtime location is
provided only through `PRIVATE_IMPORT_PATH`.

## Repository controls

`.gitignore` denies SQL, CSV, and private-data paths by default. The only SQL
exception is:

```text
database/schema/student_document_management_schema.sql
```

`.env.example` remains allowed. Environment-specific `.env` files, private
keys, credential files, and secret files are denied by the guard.

## Guard behavior

`scripts/check-private-data.ps1` checks:

- unmerged working-tree state;
- tracked, staged, untracked, and ignored repository paths;
- SQL, CSV, private import, and private data paths;
- `.env` and common credential/secret file patterns;
- working and staged sanitized SQL content for `INSERT`, `REPLACE`, and
  `LOAD DATA`;
- an optional `PRIVATE_IMPORT_PATH` for absolute, existing, out-of-repository
  location.

The guard does not search the machine for SQL files and never prints a path,
credential, SQL payload, or PII. Its only output is `PASS` or `FAIL`.

## CI and operational policy

`docs/PRIVATE_DATA_POLICY.md` requires:

- private imports to stay outside Git and CI;
- CI to leave `PRIVATE_IMPORT_PATH` unset;
- CI and automated tests to use only sanitized schema and fake fixtures;
- logs, caches, reports, and artifacts to contain no PII;
- P1-06 to call the repository guard;
- P9 rehearsal to use a private controlled environment, owner, deletion
  deadline, and non-sensitive deletion evidence;
- temporary files to use verified explicit paths and be deleted safely without
  broad cleanup or automatic deletion of unexpected duplicates.

No GitHub Actions workflow is added by P0-04.

with the approved local `PRIVATE_IMPORT_PATH` and again against the staged
